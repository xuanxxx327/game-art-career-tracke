# Game Art Career Tracker

Prototype monitor for game-art internships. It is **not yet a verified jobs feed**. A result is an unverified candidate, not a confirmed opening.

- Targets include China-based foreign studios, major and mid-size domestic studios, and selected overseas studios.
- Overseas eligibility, visas and internships must be verified from official job descriptions.
- Checks public career pages without bypassing access controls.
- GitHub Actions runs daily at 01:20 UTC (09:20 Beijing time); scheduled runs may be delayed.
- View run output in Actions → Game Art Career Monitor → Artifacts → recruitment-results.
- No Supabase connection, public website, or notifications yet. Never commit API secrets.
